# 文档索引

`docs/` 根目录只保留现行说明、实现差距和数据追溯资料；已经被现行文档替代的历史会话、
阶段清单和旧审计不继续作为项目入口。

## 新会话入口

开始任何新开发会话时，先阅读：

1. [`../AGENTS.md`](../AGENTS.md)：仓库级编码、数据库、Redis、权限和验证约定。
2. [`项目上下文与续作指南.md`](项目上下文与续作指南.md)：当前项目目标、参考项目路径、
   Warframe 数据表与 JSON 来源、统一数据集配置和已知边界。
3. [`项目架构与开发约定.md`](项目架构与开发约定.md)：模块职责和主要运行链路。

其中 [`项目上下文与续作指南.md`](项目上下文与续作指南.md) 是跨会话的事实摘要；
它不能替代 `AGENTS.md`，代码修改仍以仓库级约定为准。
