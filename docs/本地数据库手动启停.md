# 本地数据库手动启停

本机数据库启停脚本统一放在 `/Applications/数据库脚本`，不再放入项目仓库，避免与项目代码一同维护。
当前主脚本文件名用于记录本地数据库账号和密码：

```text
/Applications/数据库脚本/mysql-root-12345678
/Applications/数据库脚本/postgres-12345678
```

每个数据库提供独立的直接入口：

```text
/Applications/数据库脚本/mysql-start
/Applications/数据库脚本/mysql-stop
/Applications/数据库脚本/mysql-status
/Applications/数据库脚本/postgresql-start
/Applications/数据库脚本/postgresql-stop
/Applications/数据库脚本/pgsql-status
```

## PostgreSQL

当前默认适配 EnterpriseDB PostgreSQL 18：

```bash
/Applications/数据库脚本/postgresql-start
/Applications/数据库脚本/pgsql-status
/Applications/数据库脚本/postgresql-stop
```

默认配置：

```text
PG_HOME=/Library/PostgreSQL/18
PG_DATA=/Library/PostgreSQL/18/data
PG_USER=postgres
PG_LABEL=postgresql-18
```

`start` 和 `stop` 会保持 `postgresql-18` 的 launchd 开机启动处于禁用状态。首次执行需要
输入 macOS 管理员密码。安装位置或数据目录变化时，可通过环境变量覆盖：

```bash
PG_HOME=/custom/postgresql PG_DATA=/custom/data \
  /Applications/数据库脚本/postgres-12345678 start
```

DataGrip 的本地工具路径：

```text
/Library/PostgreSQL/18/bin/psql
/Library/PostgreSQL/18/bin/pg_dump
/Library/PostgreSQL/18/bin/pg_restore
```

## MySQL

MySQL 脚本自动识别两种本地安装方式：

- Oracle 官方 `pkg` 安装包：默认目录 `/usr/local/mysql`，如本机的 MySQL 8.4.10。
- Homebrew：`mysql@8.4`、`mysql` 和 `mysql@8.0`，优先选择 `mysql@8.4`。

```bash
/Applications/数据库脚本/mysql-start
/Applications/数据库脚本/mysql-status
/Applications/数据库脚本/mysql-stop
```

Oracle `pkg` 版会禁用 `com.oracle.oss.mysql.mysqld` 的开机自动加载，再以 `_mysql` 系统账户
手动启停服务；首次执行 `start` 或 `stop` 需要输入 macOS 管理员密码。数据库账号密码不写入
脚本。

Homebrew 版启动使用 `brew services run`，不会注册为登录时自动启动。只安装
`mysql-client@8.4` 可以满足 DataGrip 原生导入导出，但不能启动本地 MySQL 服务。

需要明确选择版本时：

```bash
MYSQL_FORMULA=mysql@8.4 /Applications/数据库脚本/mysql-root-12345678 start
```

Oracle `pkg` 安装目录或数据目录不同，可显式覆盖：

```bash
MYSQL_INSTALLATION=pkg MYSQL_HOME=/usr/local/mysql MYSQL_DATA=/usr/local/mysql/data \
  /Applications/数据库脚本/mysql-root-12345678 start
```
