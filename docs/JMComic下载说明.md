# JMComic 下载说明

JM 命令优先取得整本下载信息，只有整本文件不可用时才回退逐图下载。实现必须控制内存、下载大小和页数，
并保证最终 PDF 页序与漫画自然页序一致。

## 下载流程

1. 创建 JM 客户端；账号和密码同时配置时才登录。
2. 请求整本下载信息。
3. 有有效下载地址时以流方式下载整本文件。
4. PDF 直接校验页数和大小；ZIP 安全解压图片后使用既有 PDF 服务生成文件。
5. 整本地址为空、鉴权失败、网络失败或格式不支持时，以受限并发下载各章节图片。
6. 分图文件按自然页序排序后生成 PDF；整本与逐图均失败时，逐图异常保留整本失败为 suppressed exception。

并发只用于网络下载，页序由稳定的自然排序控制，不能以并发完成顺序生成 PDF。

## 限制与配置

- 整本文件、ZIP 解压和 PDF 输出都受 `max-download-bytes`、`max-pages`、`max-pdf-bytes` 限制。
- 不得将完整下载响应一次性读入 JVM 堆。
- 账号凭据只能通过环境变量或本地私有配置注入，不能提交到仓库。
- 整本下载可通过 `whole-file-enabled` 和 `whole-file-timeout` 控制。

匿名整本下载接口曾出现“请求成功但下载字段全为空”的情况，因此它不是稳定保证。配置有效账号后会重新尝试；
仍未得到有效整本地址时，受限并发逐图下载是正式降级路径。
