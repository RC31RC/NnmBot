## 模块边界

```text
nnm-app -> nnm-admin / nnm-warframe / nnm-core / nnm-render
nnm-admin -> nnm-core / nnm-common
nnm-warframe -> nnm-core / nnm-render / nnm-common
nnm-render -> nnm-core / nnm-common
nnm-core -> nnm-common / rdt-spring-boot-starter
nnm-common -> 无业务模块
```

| 模块 | 职责 |
| --- | --- |
| `nnm-common` | 错误模型、响应模型、HTTP、重试、校验和无业务域通用能力；不得反向依赖业务模块。 |
| `nnm-core` | OneBot、QQ 官方机器人、多渠道消息、命令 SPI、群组积分、JMComic 和后台任务状态业务。直接依赖 RDT starter。 |
| `nnm-render` | 模板、图片/PDF 渲染和受控的渲染 SPI。 |
| `nnm-warframe` | Warframe 命令、外部协议、静态数据、WorldState、市场和论坛。 |
| `nnm-warframe/task` | WorldState 轮询、仲裁刷新、预热和 Warframe 通知调度。 |
| `nnm-admin` | `/api/admin/v1`、Sa-Token、RBAC 和后台管理业务。 |
| `nnm-app` | Spring Boot 组装、运行配置和基础集成测试。 |

Controller 只负责协议和权限，业务逻辑放在 Service；Repository 只承担 Spring Data JPA 查询。
跨模块分页使用 `PageResult`。业务前置条件使用 `BusinessAssert` 和稳定 `ErrorCode`。

`common.task` 只保留任务协议与接口，内存/Redis 实现在 `core.task`。
不再设置 `nnm-infrastructure` 接入模块；通用租约、节点身份保护和 Redis 客户端配置由 RDT 自动装配。
适合方法调用边界的锁、ID、缓存写入、消息发送优先使用 RDT 注解；跨回调租约和状态读取仍显式调用。
账号连接协调仍归 `core.channel.runtime`，Warframe 快照与刷新消息归
`warframe.cache`，定时入口归业务模块的 `task` 包（例如 `warframe.task`），不为接入 Redis 拆散业务域。
具体实现与运行边界见 [RDT接入与多实例运行.md](RDT接入与多实例运行.md)。

## 命令与渠道

```text
平台事件
  -> 渠道 ContextFactory
  -> BotMessageContext
  -> CommandRegistry
  -> CommandDispatcher
  -> CommandExecutionPipeline
  -> BotPlugin.handle()
  -> CommandResponseDispatcher
  -> 渠道响应策略
```

- `CommandRegistry` 以规范化命令和别名匹配插件；`BotPlugin.command()` 必须非空，忽略大小写和首尾空格后全局唯一。
- `CommandDispatcher` 隔离插件 `match()` 异常。已匹配插件的 `handle()` 异常由统一执行边界处理，不能再交给其他插件重复匹配。
- `CommandExecutionPipeline` 统一处理权限、冷却、积分、退款和异常提示。命令中仅保留可解释的业务降级或语法边界异常处理。
- `CommandResult` 的 `data` 是 `TEXT`、`IMAGE`、`FILE`、`MARKDOWN` 四种输出模式共用的展示数据；渠道覆盖可以为 `NONE`。
- 渠道实例、启停、触发词、权限、冷却、积分和输出配置由数据库管理。`code` 是稳定配置/权限编码，用户触发词来自数据库。

## 数据与运行约束

- ORM 统一为 Spring Data JPA + Hibernate；普通动态筛选优先 JPA Specification。
- 外部地址、超时、重试、代理、缓存容量和执行器参数使用 `@ConfigurationProperties`，不能散落 `@Value`。
- JVM 业务缓存使用 cache2k；Caffeine 仅保留为评估回退，不在两套缓存框架上并行新增业务缓存。
- 外部 `RestClient` 默认校验 TLS。`nnm.http.trust-all-certs=true` 只能临时排查本地代理或证书链问题。
- 通用异步和调度任务使用 `ExecutorConfig` 及 `nnm.executor.*` 有界执行器；新增并发需同时评估数据库连接池上限 5、外部限流和 4GB 部署预算。
- 文件写入使用同目录临时文件、刷新落盘和原子替换，并传播明确异常。
- 管理接口以 Sa-Token 和稳定权限码 `业务域:资源:动作` 作为安全边界；前端权限指令只改善交互。

## 渲染

默认使用 `openhtmltopdf`，复杂 CSS 可通过配置使用 Playwright。外部渲染 JAR 只允许可信来源，须实现
`RenderEngineProvider` 并经显式开关加载；运行时不支持热切换。模板和命令展示 DTO 的字段契约必须一致，
模板不得重新解析原始 JSON 或自行隐藏业务字段。
